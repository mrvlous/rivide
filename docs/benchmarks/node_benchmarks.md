# Benchmarks: Node.js Runtime Performance

Instructions for executing Node-API runtime benchmarks in JavaScript/TypeScript.

## 1. Execution

From repository root:

```bash
make node-bench
```

Or within `bindings/node/`:

```bash
cd bindings/node
npm run bench
```
